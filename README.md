# ダイヤトルン Player 🐒

Pixel 7 を主用途にした、広告なし・外部通信なしのシンプルなローカル音楽プレイヤーPWAです。

## v0.1.0 の方針

まず普通のプレイヤーとして使えることを最優先にします。

- アルバムフォルダ選択
- 曲一覧
- 選曲・再生
- 前曲 / 次曲
- シーク
- シャッフル
- リピート
- プレイヤー内部の微小音量（100 / 50 / 25 / 10%）
- ホーム画面起動
- アプリ本体のオフライン起動

音楽ファイルそのものはPWA内へ保存・キャッシュしません。
起動後に端末上のアルバムフォルダを選択して再生します。

## 👾 実験室

入口だけあります。v0.1.0 では DSP は BYPASS 相当で、EQ / RTA / Delay / テスト信号等は実装しません。

## GitHub Pages

リポジトリ直下へこの一式を置き、GitHub Pages を有効にしてください。
すべて相対パスなので、`https://<user>.github.io/diatorun-player/` のようなサブパス公開を想定しています。

## ファイル構成

```text
diatorun-player/
├─ index.html
├─ manifest.webmanifest
├─ sw.js
├─ icons/
│  ├─ icon-192.png
│  └─ icon-512.png
└─ README.md
```

## 注意

PWAを完全に終了・再起動した場合、ブラウザの安全制約により、前回選択したローカル音楽フォルダを自動で再取得することはしません。
再起動後は必要に応じて「アルバムを選ぶ」から再選択してください。
